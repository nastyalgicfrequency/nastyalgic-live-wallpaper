# Nastyalgic Live Wallpaper

Animated live wallpapers with a 90s hip-hop/R&B aesthetic, built for Lively Wallpaper and Plash.

## Wallpapers

- `wallpapers/nf-90s-loop-v1.html` — v1 loop. Dark warm palette, spinning vinyl, pulsing equalizer, film grain, faint VHS tracking glitch, low-opacity NF wordmark texture.

## Running it on Mac (Plash)

1. Install [Plash](https://apps.apple.com/us/app/plash/id1494023538?mt=12) from the Mac App Store (free).
2. Download `wallpapers/nf-90s-loop-v1.html` from this repo to your Mac.
3. Open Plash, click the menu bar icon → **Add website** → **Choose local file** → select the downloaded file.
4. Done. It'll render on your desktop, behind your icons.

Note: if you're running multiple displays, Plash lets you pick which display each website/file targets — add it again and choose a different display if you want it on more than one.

## Running it on Windows (Lively Wallpaper)

1. Install [Lively Wallpaper](https://apps.microsoft.com/detail/9ntm2qc6qws7) (free, Microsoft Store).
2. Drag the `.html` file into the Lively window, or use "Add wallpaper" → select the file.

## Notes

- Single self-contained file, no build step. Only external dependency is a Google Fonts stylesheet (Bungee).
- Animations are deliberately slow/ambient — built to sit behind desktop icons without fighting for attention while you work.
